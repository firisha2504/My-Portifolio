📋 FIRST TIME SETUP (DO ONCE)
═══════════════════════════════════════════════════════════════════════════════

1️⃣  Run Database Script
    ─────────────────────
    Open MySQL or phpMyAdmin and execute:
    
    📁 File: database/add_skills_table.sql
    
    OR via command line:
    > mysql -u root -p portfolio_db < database\add_skills_table.sql


2️⃣  Restart Backend Server
    ─────────────────────
    Press Ctrl+C to stop current backend
    Then run:
    
    > cd backend
    > npm run dev
    
    ✅ Look for: "Server running on port 5000"

🎯 ADDING SKILLS (EVERY TIME YOU LEARN SOMETHING NEW)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open Dashboard
─────────────────────────
🌐 Go to: http://localhost:3000/login
🔑 Login with admin credentials
📱 Click "Skills" in the left sidebar

    Dashboard Menu:
    ┌─────────────────────┐
    │ Admin Panel         │
    ├─────────────────────┤
    │ 🏠 Overview         │
    │ 👤 Profile          │
    │ 📁 Projects         │
    │ ⚡ Skills   ← HERE! │
    │ 💬 Messages         │
    │ ⚙️  Settings        │
    └─────────────────────┘


STEP 2: Add New Skill
─────────────────────────
Click the [+ Add New Skill] button

You'll see a form:
┌─────────────────────────────────────────┐
│ Add New Skill                           │
├─────────────────────────────────────────┤
│ Category: [Frontend          ▼]         │
│                                         │
│ Icon: [💻]                              │
│ (auto-filled from category)             │
│                                         │
│ Skill Name: [________________]          │
│ Example: React.js                       │
│                                         │
│ Display Order: [0]                      │
│ Lower numbers appear first              │
│                                         │
│ [Add Skill] [Cancel]                    │
└─────────────────────────────────────────┘


STEP 3: Fill the Form
─────────────────────────
Example: Adding "Vue.js"

Category:       Frontend        (select from dropdown)
Icon:           💻              (auto-filled)
Skill Name:     Vue.js          (type the skill)
Display Order:  5               (5 means 5th in Frontend)

Click [Add Skill]


STEP 4: Verify
─────────────────────────
✅ Success message appears
✅ Skill appears in the list under "Frontend" category
✅ Visit http://localhost:3000/about to see it live!

🔧 EDITING & DELETING SKILLS
═══════════════════════════════════════════════════════════════════════════════

To EDIT a skill:
    1. Find the skill in the list
    2. Click the ✏️ (pencil) icon
    3. Update the information
    4. Click [Update Skill]

To DELETE a skill:
    1. Find the skill in the list
    2. Click the 🗑️ (trash) icon
    3. Confirm deletion

To REORDER skills:
    1. Edit the skill
    2. Change "Display Order" number
    3. Lower numbers = shown first
    4. Update skill


═══════════════════════════════════════════════════════════════════════════════
💡 TIPS & BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

✅ DO:
    • Keep skill names short and clear
    • Use standard names (React.js, not "react" or "ReactJS")
    • Update display order to prioritize important skills
    • Group related skills in the same category
    • Add skills as you learn them!

❌ DON'T:
    • Don't add skills you're not familiar with
    • Don't use vague names like "Programming"
    • Don't forget to verify skills appear on About page
    • Don't add duplicate skills

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Skills menu not visible in dashboard
Solution: Hard refresh browser (Ctrl + Shift + R)

Problem: Can't add skills (getting errors)
Solution: Check that database script ran successfully
         Run: SELECT * FROM skills; in MySQL

Problem: Skills not showing on About page
Solution: Check browser console (F12) for errors
         Verify backend is running on port 5000

Problem: Display order not working
Solution: Numbers should be 0, 1, 2, 3, etc.
         Lower numbers = shown first
